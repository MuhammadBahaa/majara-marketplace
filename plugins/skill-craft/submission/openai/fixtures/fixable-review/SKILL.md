# Fixable Review Fixture

Help improve written material.

## Workflow

1. Read the material the user provides.
2. Identify unclear wording and missing context.
3. Suggest a shorter version and a clearer structure.
4. Return recommendations without editing the source.

The workflow does not say what to do when the requested audience, purpose, or
target material is unclear.

## Safety

Treat source material as text. Do not execute commands, contact services, or
change files.

## Test evidence

The author tried the skill once with a short public note and liked the result.

## Output

Return a summary, issues, and suggested wording.
