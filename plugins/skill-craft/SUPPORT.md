# Skill Craft Support

Report reproducible problems at
https://github.com/MuhammadBahaa/majarrah-marketplace/issues.

Include the Skill Craft plugin version, host product and version, prompt,
expected behavior, actual behavior, and the smallest useful redacted fixture.

**Do not post secrets, personal data, credentials, private client code, or
proprietary skill files.** Replace sensitive values with clear redactions and
confirm that the fixture still reproduces the problem before posting it.
