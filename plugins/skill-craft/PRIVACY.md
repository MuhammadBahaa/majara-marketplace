# Skill Craft Privacy

Skill Craft is a skills-only package containing local instructions. It has no MCP
server, no authentication, no network calls, no telemetry, and no
author-operated storage. The Skill Craft author does not receive the user's
prompts or files, and Skill Craft does not store them.

The host product reads and processes the content needed to run a skill. That
processing is performed by the host under the host product's own terms and
privacy policies. Users should review those policies before providing content.
